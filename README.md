# 🌸 Moomins Website

This is my **first mini website**, created as a practice project to learn and experiment with **Bootstrap 5**.  
It’s a simple static site dedicated to the Moomin characters, books, and products, built with **HTML**, **CSS**, and **Bootstrap**.

---

## 📸 Overview

The website includes:

- Navigation menu with sections: Characters, Tove, Moominvalley, Books, Products
- Hero section with background image and "Buy Now" button
- Character cards (Little My, Moominmamma, Moominpappa)
- Section about Tove Jansson and Moominvalley
- Book gallery
- Product grid with prices (Mug, Bag, Tea, Notebook, Metal Box, Toy…)
- Feature icons (Secure Payments, Free Shipping, 24/7 Customer Service)
- Footer with navigation, contact info, social media links, and newsletter form
